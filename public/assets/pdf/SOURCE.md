# Randomtrip PDF assets

PDFs use the approved shared logo at `../logos/logo_pdf.png`. The historical
extracted logo has been removed; do not add a separate PDF copy.

These discrete brand marks and generic icons were extracted from the five
user-provided Randomtrip PDF references. They contain no booking/customer data,
QR destinations, sample reservation references, or whole-page backgrounds.
Dynamic content is always authored anew by the HTML templates.

SVGs preserve the original vector outlines, with one source-unit padding in each
viewBox. Only artwork used by the HTML templates is retained. Menu numbering and
the experience descriptor/divider are generated as localized HTML and CSS.

The shared HTML asset loader is the icon catalog. Its tests verify that every
retained SVG is loaded and used across the five document families in both locales.
